# Configuring-File-Sharing-and-Permissions


  **Objective: Set up file sharing within the AD environment**

1. On the Windows Server, we create a new folder under the C: Drive, and we name it HR
2. Next, we will share this file with the network. Right click on HR > properties> Sharing >advanced sharing>  tick the box of Share this folder > ok 
3. Next, we click on Security for NTFS permissions. Click on Creator Owner> edit> add> type object name as #HR_Department > Allow them full control> Apply.
